# Use only redistributable sources, and restrict published passage text

The data is to be released under CC BY 4.0, and it is much cheaper to enforce this at the start than to remove restricted data from a released graph. Only sources whose licences allow redistribution are integrated, and each is recorded in a licence manifest. Restricted sources such as DrugBank, OMIM and KEGG may be referenced by identifier only.

Abstracts often remain under copyright, so evidence span text is published only for articles under an open licence. For other articles we publish the PMID and text offsets, and users can retrieve the text with a provided script.
