## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues on `Nurtal/SDKG`, using the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The repo uses the default labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human` and `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
